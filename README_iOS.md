XGMAP — iOS PWA (USGS)

This is a static Progressive Web App that polls the USGS earthquake feed and displays events on a touch-optimized map for iPhone/iPad.

Quick steps to host on GitHub Pages:
1. Create a GitHub repository named xgmap.
2. Upload these files to the repo root.
3. Go to Settings → Pages → Branch: main / root.
4. Save. GitHub will provide a Pages URL.
5. Open the URL in Safari, then tap Share → Add to Home Screen.

Notes:
- The app is client-only and fetches USGS directly from the browser.
- This is a static app; no backend is required.
- For more sources, add a backend API and update the app fetch URLs.
